# 内容模型

## 1. 内容定位

第一版偏专业百科，不做评分和消费推荐。内容要帮助用户理解牛排知识体系，而不是直接告诉用户“买哪块”。

## 2. 核心模块

| 模块 | 说明 | 第一版状态 |
| --- | --- | --- |
| 部位 | 牛排部位、结构、别名、市场说明 | 核心实现 |
| 术语 | 分割、等级、贸易、加工、熟成等术语 | 核心实现 |
| 产地 | 国家/地区、体系、出口语境 | 基础展示 |
| 等级 | USDA、MSA、日本 A5、澳洲 MB 等 | 基础展示 |
| 贸易 | 标签、厂号、冷鲜/冷冻、准入逻辑 | 主题入口 |
| 厂号 | 工厂、注册编号、准入信息 | 后续实现 |

## 3. 内容深度

每个正式条目采用中等深度：

- 简短定义。
- 结构化字段。
- 600-1000 字左右主体说明。
- 相关条目。
- 常见误区或命名说明。

## 4. 命名规则

- 中文主名称采用大陆常见叫法。
- 别名收录英文、港台和市场常见叫法。
- 对混用严重的名称单独说明，不强行简单合并。

## 5. 来源策略

内容分三类：

- 稳定知识：部位、基础术语、烹饪原理，可先生成后校对。
- 半稳定知识：等级体系、产地特点，需要参考权威资料。
- 强时效知识：准入厂号、贸易政策、进口规则，必须标注来源和核验日期。
