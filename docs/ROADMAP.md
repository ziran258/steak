# Roadmap

## Phase 0：项目管理和架构确认

目标：明确需求、技术架构、范围和任务优先级。

交付物：

- BRD。
- 技术架构文档。
- Backlog。
- 内容模型说明。
- 部署计划。

## Phase 1：展示型 MVP

目标：做出可浏览的中英文 Wiki 原型。

交付物：

- 中英文首页。
- 部位列表和详情。
- 术语表。
- 产地、等级、贸易入口。
- 初始 seed 数据。

## Phase 2：部署上线

目标：在腾讯云服务器通过 Dokploy 跑起来。

交付物：

- Docker 构建通过。
- Dokploy 连接 GitHub。
- PostgreSQL 可用。
- 域名解析到服务器。
- HTTPS 可用。

## Phase 3：内容扩充

目标：从样例内容扩展到正式内容库。

交付物：

- 50+ 条内容。
- 来源和核验日期。
- 更完整的产地、等级和贸易页面。

## Phase 4：可选产品化

目标：根据使用情况决定是否做交互和后台。

候选方向：

- 管理后台。
- 用户收藏。
- 投稿审核。
- R2 图片管理。
- 高级搜索。
