# BRD：牛排 Wiki

## 1. 项目背景

在学习和进阶牛排制作的过程中，需要系统理解牛肉部位、产地、等级、厂号、进口贸易、加工和烹饪之间的关系。现有内容多为零散教程或消费推荐，缺少结构化、可扩展的中文/英文知识库。

## 2. 项目目标

- 建立一个中英文牛排与牛肉知识 Wiki。
- 第一版只实现信息展示，不做后台、登录、支付和用户互动。
- 以专业百科为主，后续可扩展家庭烹饪、餐厅点餐和购买决策内容。
- 项目同时用于练习云服务器、Docker、Dokploy、PostgreSQL、域名和部署流程。

## 3. 目标用户

- 对牛排部位、等级、产地和进口标签感兴趣的学习者。
- 正在进阶家庭牛排制作的人。
- 想理解牛排馆菜单和零售标签的人。
- 后续可扩展到餐饮从业者、采购和供应链学习者。

## 4. 第一版范围

### 包含

- 中英文路由。
- 首页。
- 牛排部位列表。
- 牛排部位详情。
- 术语表。
- 产地、等级、贸易主题的基础展示入口。
- 基础搜索和筛选。
- 占位图片。
- 初始 seed 内容。
- Docker/Dokploy 部署准备。

### 不包含

- 后台管理。
- 用户登录。
- 收藏、评论、评分、投稿。
- 支付。
- Redis 缓存。
- 邮件系统。
- 对象存储上传。
- 厂号数据库的实时准入核验。

## 5. 成功标准

- 可以通过中英文页面浏览核心知识模块。
- 至少有一批高质量样例内容验证页面结构。
- 项目可以在本地和服务器部署路径上继续推进。
- 数据结构能支持后续扩展到产地、等级、厂号和贸易信息。
